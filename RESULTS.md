# Results

No new controlled benchmark has been executed in this branch.

Historical evidence is retained in the repository but is explicitly labeled exploratory.

## Required reporting

| Quantity | Report |
|---|---|
| Solved task rate | objective verifier |
| Candidate budget | number of generations |
| Debug budget | number of execution/fix steps |
| Calls | total successful/failed API calls |
| Runtime | end-to-end wall clock |
| Selection | objective test rule |

Do not report a single 'best' model or pipeline variant without a fixed benchmark population and compute budget.
